# 荒野装备谱系设计

本文档把武器、防具、副手与法杖按“谱系”整理。每个谱系都包含弱/中/强档装备、合成方式、详细效果和可新增的技能/状态。

## 通用新效果

| 效果 | 说明 |
|---|---|
| 断招 | 命中时取消敌人当前前摇或蓄力。对 Boss 只缩短前摇。 |
| 麻痹值 | 多次命中叠加，满值后短暂眩晕。适合蜂刺系。 |
| 缠绕 | 降低移动速度，强缠绕会定身。 |
| 毒谱 | 不同毒药分支：普通毒、虚弱毒、饥饿毒、神经毒。 |
| 回旋 | 投出后返回，去程和回程都可命中。 |
| 蓄力 | 按住攻击键提高伤害/射程，但消耗更多体力。 |
| 地形加成 | 在丛林、水边、夜晚等环境获得额外效果。 |
| 禁忌代价 | 强力装备会增加饥饿消耗、降低速度或吸引敌人。 |

## 平衡原则

1. 远程强度依赖弹药和装填时间。
2. 强控制武器降低直接伤害。
3. 重甲提高容错，但牺牲速度和冲刺。
4. 禁忌/绿母装备有饥饿代价。
5. 夜间/地形装备在特定环境强，离开环境变普通。
6. 陷阱流强但需要预判，并可能误伤村民。
